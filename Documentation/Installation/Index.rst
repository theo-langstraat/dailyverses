Installation
============

Traditional setup
-----------------

Go to System -> Extension -> Get extensions in the Typo3 backend, click **Update Now** and search voor dailyvers
 
Install extension via composer command
--------------------------------------

Go to your folder where the root composer.json file is located
Type: composer require theolangstraat/dailyverses to get the latest version that runs on your TYPO3 version.

After installation, make sure to clear all caches.

Requirements
------------

- TYPO3 v13 or higher  
- PHP 8.3 or higher  

Optional
--------
- Bootstrap Package 15.0 or higher
